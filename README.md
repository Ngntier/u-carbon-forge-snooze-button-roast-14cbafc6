A one-line roast of an alarm clock that rings at 6 AM on a Saturday: instead of the usual complaint about hating mornings, it paints the clock as the only thing in the house that treats the weekend like a rumor it refuses to believe — a stubborn little machine so loyal to the weekday that Saturday itself sounds like gossip to it.

python3 main.py
